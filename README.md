# ✨ Stardance • Personal Space & Portfolio

> *"A personal site is a small space on the internet about you."* — Built for the Hack Club Personal Site Workshop.

Welcome to **Stardance** (`dumass-dev/stardance-web`), the cosmic personal website of **Shuaib** ([@dumass-dev](https://github.com/dumass-dev)). Crafted with **pure semantic HTML5**, **modern Vanilla CSS**, and **performant Vanilla JavaScript**.

---

## 🌌 Overview & Highlights

- **Pure Vanilla Stack**: Zero bundlers, zero framework dependencies. Runs instantaneously in any modern browser.
- **Interactive Background Starfield**: 60 FPS HTML5 Canvas simulation with dynamic Euclidean proximity checks that form transient constellations and react to cursor physics.
- **The Stardance Sandbox**: A playful creative laboratory where visitors can click and drag to spawn dancing stars, trigger supernova explosions, invert gravity, and hear procedural pentatonic chimes synthesized via the **Web Audio API**.
- **Futuristic Glassmorphic Aesthetic**: Deep-space color palette (`#070913`), smooth glowing accents (`#38bdf8`, `#a855f7`, `#fbbf24`), custom typography (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`), and translucent frosted cards.
- **Curated Constellations (Projects)**: Filterable project showcase with deep-dive preview modals and repository links.
- **Cosmic Logs (Dev Blog)**: Integrated modal reader with reflections on web craftsmanship and generative coding.
- **Interactive Orbit (Contact)**: Instant one-click email copying (`shuaib.melekodesseri@gmail.com`), contact form simulation with toast alerts, and social links.

## 🚀 Running Locally

You don't need any complex installation or npm packages! You can run this website directly on your computer using any of these simple methods:

### Option 1: Python Local Server (Recommended)
Open your terminal in this repository folder and run:
```bash
python -m http.server 8080
```
Then open your browser at:
`http://localhost:8080`

### Option 2: VS Code Live Server
1. Open this repository in **VS Code**.
2. Install the **Live Server** extension if you haven't already.
3. Right-click `index.html` and click **"Open with Live Server"**.

### Option 3: Direct File Open
You can also directly double-click `index.html` in your file explorer to open it in your default web browser!

## 🌐 Deploying to GitHub Pages (Free Hosting)

Follow these steps to make your site publicly accessible on the internet:

1. **Commit and Push your code** to GitHub:
   ```bash
   git add .
   git commit -m "feat: initial release of Stardance personal website"
   git push -u origin main
   ```
2. **Open GitHub**:
   - Go to your repository at `https://github.com/dumass-dev/stardance-web`.
3. **Go to Settings**:
   - Click on the **Settings** tab at the top.
   - On the left sidebar, click on **Pages** (under "Code and automation").
4. **Configure Build & Deployment**:
   - Under **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/(root)`.
   - Click **Save**.
5. **View Your Site**:
   - GitHub Pages will build your site in about 1–2 minutes.
   - Refresh the page and your live link will appear (e.g., `https://dumass-dev.github.io/stardance-web/`).
